Proof-gated semantic batching for Go

BatchWeaver finds supported scalar access patterns, proves a conservative transformation, previews the diff, and runs transformed tests through an overlay before source changes are considered.

Beta: APIs may change. Review every diff and run your full suite. Unsupported patterns remain scalar.

Five-minute start

go install github.com/Voskan/BatchWeaver/cmd/batchweaver@v0.1.0-beta.1
batchweaver version
batchweaver doctor
batchweaver scan ./...
batchweaver transform plan ./...
batchweaver test -- -race ./...

The command pins the immutable beta tag. Importable package documentation and compile-tested examples are available on pkg.go.dev.

Safety model

Proof first

No supported transformation proceeds without explicit proof obligations. Unknowns are rejections, not optimism.

Preview first

Source is unchanged by default. Plans, diffs, overlays, type checking, and transformed tests precede materialization.

Boundaries preserved

Ordering, errors, cancellation, deadlines, partitions, authorization, transactions, and result contracts are part of eligibility.

Compatibility

Go 1.26.5 is the supported toolchain. Native evidence is strongest on macOS arm64. Linux amd64/arm64, macOS amd64, and Windows amd64 archives are cross-built and verified with the limitations recorded in the matrix.

Adopt conservatively

  1. Evaluate in a non-production clone.
  2. Run scan and proof reports.
  3. Add explicit providers only for verified contracts.
  4. Preview and test through overlays.
  5. Use shadow verification, canaries, budgets, and a rehearsed rollback.
