# Runtime ABI reference

The generated-bridge ABI (`batchweaver.bridge/v1alpha1`) is the typed contract
between generated code and the runtime, provided by the public `bridge` package.

| Symbol | Purpose |
| --- | --- |
| `bridge.Operation[R, K, V]` | immutable per-operation binding (OpID + scalar fallback) |
| `Operation.Call(ctx, receiver, key)` | routes through the runtime or falls back to the scalar call |
| `bridge.WithOperation[K, V](ctx, opID, *runtime.BoundOperation)` | installs a typed bound operation into the scope context |
| `bridge.Flush(ctx)` / `bridge.Barrier(ctx)` | flush pending operations in the active scope |
| `bridge.ABIVersion` | the ABI version string |

## Invalidation

The ABI version is recorded on every runtime transformation (`runtime_abi` in the
plan) and contributes to the plan digest. A change invalidates generated bridges
and plans. Generated files carry the standard `// Code generated by BatchWeaver.
DO NOT EDIT.` header.

## Guarantees

- No reflection on the call path.
- Exact scalar fallback when no bound operation is installed.
- Result-shape dispatch never uses runtime type assertions.
