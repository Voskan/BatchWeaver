# Beta Exit Criteria

Stable v1.0 requires all of the following evidence, not a popularity threshold:

- no unresolved P0/P1 correctness, isolation, or security defect;
- repeated immutable prerelease publication and rollback rehearsal;
- verified public installs on the supported platform matrix;
- real external compatibility reports and at least one reviewed integration;
- public API/schema/runtime ABI review and migration policy proven in practice;
- Extension Host and editor compatibility evidence;
- stable semantic, fuzz, race, performance, and vulnerability gates;
- documentation feedback addressed and private reporting verified;
- no known release blocker and an explicit maintainer decision.

Silence or lack of beta feedback is not evidence that these criteria pass.
