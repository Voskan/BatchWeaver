# GitHub Beta Announcement Draft

BatchWeaver `v1.0.1` is a proof-gated Go compiler/runtime toolkit for
evaluating supported scalar-to-batch transformations. It provides conservative
analysis, proof evidence, diff/overlay testing, typed runtime batching, verified
artifact checksums, SBOMs, and explicit rollback paths.

The Tier 1 Go API is frozen under Semantic Versioning; artifacts are not yet signed. Go 1.26.5 is the
tested toolchain; several concrete client bindings and full editor-host evidence
remain incomplete. Start with scan-only mode and share sanitized, reproducible
feedback through the repository forms. Do not post this draft until the public
release and every link are verified.
