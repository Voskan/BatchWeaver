# Hacker News Submission Draft

Title: BatchWeaver: proof-gated semantic batching for Go (public beta)

We built an experimental Go compiler/runtime toolkit that finds supported N+1
patterns, proves conservative semantic obligations, previews transformations,
and tests them through overlays before source changes. It is intentionally
narrow: unsupported cases remain scalar, several client integrations are still
absent, and this beta asks for correctness/compatibility feedback rather than
claiming universal speedups. Repository and release links must be inserted and
verified before posting.
